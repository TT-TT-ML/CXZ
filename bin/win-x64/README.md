# Prebuilt binaries

The engine (`CXZ.exe`) and the GUI (`CXZQt.exe`) are not committed here: this repository is
text-only, and the connector used to publish it cannot carry binary blobs. They are distributed
as a package next to this repository (see the project page), or built from `gui/` against the
closed-core engine.

# 预编译二进制

引擎 `CXZ.exe` 与前端 `CXZQt.exe` 不在仓库里：本仓库是纯文本的，发布通道无法上传二进制。
它们以发布包形式随仓库提供，或用 `gui/` 源码针对闭源核心自行编译。
